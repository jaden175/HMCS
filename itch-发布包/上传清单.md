## 步骤

### 1️⃣ 注册
打开 <https://itch.io> → **Register**（邮箱 + 密码）→ 登录。

### 2️⃣ 建项目
- 右上角 **Create new project** → **Downloadable**（选这个！不是 HTML5）
- **Title**：`HMCS — Hallo Minecraft Space`
- **Short description**（一句话）：
  > A clean, minimal Minecraft launcher with original UI. Supports 26.x releases, Fabric/Forge, offline & Microsoft & third-party auth, automatic Java management and one-click Modrinth mod install.
- **Classification**：Tool
- **Tags**：`minecraft` `launcher` `modded` `fabric` `forge` `java` `tools`

### 3️⃣ 传文件（Uploads 标签页）
把下面三个文件拖进上传区（可以一次拖多个）：

- `HMCS-0.1.0-win.zip` → 平台标签勾 **Windows**
- `HMCS-0.1.0-amd64.deb` → 平台标签勾 **Linux**
- `HMCS-0.1.0-source.zip` → 平台标签勾 **Source / Code**

> 上传大文件时 itch 会显示进度条，别关页面；218MB 大概要几分钟。

### 4️⃣ 定价
**Pricing** 标签页 → 选 **No payment**（完全免费）或 **Donate what you want**（最低 0 元，让读者自愿赞助）。
选后者的话，"Suggested price" 填 0，"Only allow downloads" 保持不勾。

### 5️⃣ 配图
- **Cover image** → 上传 `itch-cover.png`
- **Screenshots** → 上传 `promo-features.png` 和 `promo-download.png`

### 6️⃣ 写介绍
**Description** 里粘贴 `描述-EN.md` 的内容（Markdown 直接粘，图片引用改成 itch 已上传的图，或者删掉那行 `![features](...)`）。
> 也可以中英都放：英文在前，中文用 `---` 分隔。

### 7️⃣ 发布
- 页面顶部把 **Visibility** 改成 **Public**
- 勾 **This page is listed in search results**
- 点 **Save** → 你的页面就上线了 🎉

**固定地址**：`https://你的用户名.itch.io/hmcs`

## 发布后

1. 把 `https://你的用户名.itch.io/hmcs` 填进启动器的「设置 → 软件更新」？——不，那是给**更新用**的。
   正确用法：把 `update.json` 放到你能长期访问的地方（对象存储/服务器），填进「设置 → 软件更新 → 更新源」。
2. 想让国内用户下载更快：itch 的文件可以再传一份到**腾讯云 COS / 七牛云**，页面里加一个「国内下载」按钮（用 `bash tools/build-site.sh <页面地址> --files-base=<对象存储地址>` 重新生成带双下载入口的页面）。
3. 以后出新版本：itch 页面 Uploads 里追加新文件 + 写一条 **Devlog**（订阅者会收到通知）。
