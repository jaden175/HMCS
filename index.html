常见问题

下载与使用中最常被问到的几个问题。

点了开始游戏没反应 / 一直下载不下来？

最常见原因是数据目录权限：如果曾用管理员身份（sudo / 右键"以管理员身份运行"）启动过 HMCS，数据目录属主会变成管理员，之后正常方式启动时 Java 和游戏资源就全部写入失败且可能不报错。

Linux 修复：终端执行 sudo chown -R $USER ~/.config/HMCS，重新打开启动器即可，会自动补齐缺失的 Java 与资源。

Windows 修复：不要用管理员身份运行 HMCS。若目录权限已被破坏，用管理员打开 PowerShell 执行 takeown /f "$env:APPDATA\HMCS" /r /d y 和 icacls "$env:APPDATA\HMCS" /grant "$env:USERNAME:(OI)(CI)F" /t，之后正常双击启动。日常使用请始终双击运行，不要选"以管理员身份运行"。

Windows 下载后怎么安装？

解压 HMCS-0.1.0-win.zip，双击目录内的 install.cmd，脚本会自动复制程序、创建桌面与开始菜单快捷方式并写入卸载信息。也可以直接运行目录里的 hmcs-launcher.exe 免安装使用。

下载到一半断了怎么办？

直接重试即可。下载采用流式落盘 + HTTP Range 断点续传，已下载部分会保留并接着下，不会从头再来；完成后还会做 SHA1 校验。

提示缺 Java 或内存过大？

两者都会自动处理：超过物理内存 75% 时自动下调堆内存；缺少 Java 时按版本要求自动下载（Adoptium，失败自动切清华 TUNA 镜像），仍失败则回退使用本机已安装的 Java。

26.x 版本怎么下不到？

启动器按官方清单全量支持，26.1 / 26.2 / 26.3 直接可选；26.4 目前只有快照，正式版发布后会自动出现在列表里，无需更新客户端。

用的是 PCL 的代码吗？

不是。界面只对齐操作习惯，所有代码、图标与文案均为本项目原创实现，未复制 PCL 任何源码或素材。
